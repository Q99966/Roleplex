# 工作流操作面板验收

日期：2026-09-22。范围为[三批计划](../plan/workflow-feedback-usability-v1.md)的第三批：一条主工具栏、一个画布、一个上下文面板，记录与高级配置按需打开。继续复用现有图管理、反馈处置、预算及浏览器草稿存储，没有新增后端业务接口或数据库迁移。

环境为 WSL2/Linux、Python 3.12、Node 24、Chromium、SQLite 隔离数据库。浏览器链路使用真实前后端和确定性 fake Provider，本批不调用收费模型。真实 Provider 脚本仅同步交互入口，不能将脚本维护记作本轮真实模型通过。

## 验证范围

- 模板切换保留未提交编辑；“保存模板”和“提交本次运行调整”分别修改对应对象。运行图返回原模板后不会沿用运行目标。
- 刷新恢复当前运行与历史版本；历史读取失败保持只读，恢复成功后仍须明确返回当前运行才可修改。历史反馈查看、定位与来源详情不恢复处置按钮。
- 草稿冲突保留人工内容；另存后的源草稿仍可手动恢复，但不在切回原模板时自动带回旧冲突。取某一目标的最新副本，不能跳过较新的干净副本恢复旧脏版本。
- 从节点提交反馈、委托协调、局部补图、验证关闭及版本竞争；节点内请求局部调整，切换记录再回来保留本次输入。
- 图提交后暂停 fake 协调 Provider，通过产品按钮取消该协调请求；已提交图和原开发执行保留，新增审查继续结束，人工确认后原运行正常完成，开发不重放。
- 本次运行完成后准备新运行，产生新的 run 和 chain，不因重用幂等键返回旧结果。
- Guest 在同一浏览器登录后不显示 Owner 私有草稿或编辑入口；工作流列表与草稿分区接口仍返回 403。
- 窄屏的详情抽屉、嵌套结果弹窗、Tab、Esc 和焦点归还；主区在抽屉打开时不可交互。原会话详情模块、节点类型/颜色、Tab 插入、Delete、连线、拖动、布局与草稿恢复继续回归。

## 覆盖边界

本轮针对桌面和 390/430 像素窄屏 Chromium。没有 Windows 原生浏览器、移动触摸设备或其他浏览器实机证据；没有 PostgreSQL 实例验证。浏览器草稿的系统崩溃丢失窗口沿用现有说明，未增加操作系统级持久化保证。

不以 fake 模型替代真实模型行为验收，不扩大协调者工具权限，也不改变已有并行循环、资源互斥和未知文件结果语义。历史服务端事实与新图、模板草稿、浏览器恢复点分别保留。
