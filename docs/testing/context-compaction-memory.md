# 主动压缩与历史检索验收

日期：2026-09-22。范围为[总体计划](../plan/conversation-context-memory-capabilities-v1.md)的 C。接口与语义以[压缩协议](../protocol/public/rest/context-compression.md)、[Memory](../protocol/public/rest/memory.md)及[数据模型](../protocol/internal/data-model.md)为准。

## 验证内容

- Owner 选择角色模型、范围/最近保留数量、摘要目标和一次性要求；不改写原消息。摘要采用后普通输入使用摘要与未覆盖原文，回退旧摘要或原文仍保留后来追加消息。
- 来源在创建时冻结；并发追加允许进入尾部，旧消息修订、删除、撤权、停止和回退指针竞争使旧结果不采用。服务器把停止原因与已确认/未知工具事实保留在摘要中，旧来源变化后摘要正文不再返回。
- 并发同请求键只创建一次维护任务，不同参数拒绝；在途任务避免重复创建。浏览器提交已成功但响应丢失时找回原任务，不重复 POST 触发模型。
- 完整消息分段后合并，每次请求的输入/输出/余量不超过所选窗口，复用同一 chain 的决策额度和连续调用索引；额度不足、无收益、模型失败、格式/引用不正确保持原版本。
- 维护请求没有聊天消息；聊天快照、普通停止按钮不把它当作角色回复。专用停止可关闭正在等待的 fake Provider；重启将未完成请求标为 interrupted，重复请求键不重放。
- 冻结模型参数只包含实际支持的字段；未知 api_key 等额外参数不复制进快照。配置变更不改用其他模型，不产生预检拒绝后的虚假调用。
- 中文词组、英文/代码标识符检索、连续分页与游标版本、原文字符范围和来源 revision 核对；当前用户请求本身不会成为 Agent 的检索命中。
- 单聊私有信息不经角色带入群聊；Owner/Guest、角色/成员、引用绑定、来源变更与再次派发前的撤权校验。工具已读取的记录保留，但失效来源不回显旧标题/原文。
- `memory_search/read` 通过真实 Agent 循环实际调用，读取值只在受控来源里，不在模型固件预埋；无工作区的普通会话和明确分配的工作流节点都可使用。
- 真实浏览器验证压缩后人工和 Agent 找回被省略细节、工具来源记录、摘要回退、共享范围拒绝、旧结果回读拒绝、窄屏停止/焦点。物理 World 重启保留已发布摘要，引用跨 World 拒绝，切回可继续核对原文。

## 会话压缩范围澄清

同日按用户反馈，移除了压缩页共用的“查看角色”，固定显示当前会话及共享范围。生成摘要的模型配置独立选择，草稿按会话保存；切换占用/检索角色不会切换压缩对象或清空要求。后端来源仍按 conversation_id 选取，role_id 仅关联模型配置和维护执行。

本次定向验证：`test_context_compaction.py` 1 项通过，确认不同发言角色的来源都被选取、只发布一份摘要且多个角色采用同一版本；`context-compaction-memory.spec.ts` 4 项通过，包含新增的范围/模型选择/草稿保持用例，另 3 项为原流程回归。构建通过，未改表结构或额外调用真实 Provider。浏览器记录 `logs/tests/e2e/fake/2026-09-22/16-31-36_8d11a7f4`；[会话范围与独立模型选择截图](../../logs/tests/e2e/fake/2026-09-22/16-31-36_8d11a7f4/artifacts/screenshots/__ab50aca7_0_0.png)。前表保留 C 批原验收记录，与这次复核区分。

## 覆盖边界

环境为 WSL2/Linux、Python 3.12、Node 24、Chromium、隔离 SQLite 和物理测试 World。全部 Provider 用例为确定性 fake，没有调用收费模型；结构、预算、权限、来源和执行链通过不代表所有真实模型的摘要质量。首版检索是可解释关键词匹配，不宣称语义向量效果。

PostgreSQL 只覆盖离线 SQL，未验证实例部署；未进行 Windows 原生、其他浏览器或移动设备实机验证。自动阈值/提示词、执行内工具轮压缩和自动采用属于 D；Skills/MCP 产品模块及世界 Orchestrator 未在本批扩展。
