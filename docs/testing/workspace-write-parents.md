## 后端验证

```bash
python -m pytest tests/test_workspace_batch_mutation.py tests/test_write_diff.py tests/test_write_diagnostics.py tests/test_execution_summary.py tests/test_workspaces.py tests/test_workspace_edit.py -q --tb=short --show-capture=no
```

最终 91 passed，59.69 秒，覆盖：

- 单项/批量自动创建多层父目录，同父目录并发；预检失败不提前创建目录。
- 整批文件/目录祖先冲突、敏感路径、链接、已有普通文件祖先、版本约束。
- 预检后路径被替换为链接；目录创建期间错误的固定拒绝语义与空目录残留。
- 创建目录后目标被另一写入者抢先创建：不覆盖对方内容，单项/批量仍保留目录计数。
- 加密详情往返保留计数，文件未提交与已有目录副作用分开；取消不丢目录计数，文件状态无法确认时仍保持未知。
- 既有 diff 降级、提交凭据、权限、版本竞争与停止原因回归。

中间一次旧测试严格断言单文件结果仅有三个字段失败，已更新为接受兼容新增的目录计数，最终上述回归全部通过。
本阶段没有新增数据库表/列，无需迁移。旧详情缺省计数保持 null，不能从当前文件系统补造历史。
