# 提示词与能力配置验收

日期：2026-09-22。范围为[总体计划](../plan/conversation-context-memory-capabilities-v1.md)的 A 批：平台/世界/角色/会话提示词配置、生效来源、角色隐藏配置保留与共同工具能力快照。

本批不实现持久会话上下文、占用进度条、压缩、Memory 检索、Skills 管理或 MCP 产品接入；这些仍按 B–F 推进。新增 0024 迁移，字段和接口以[提示词协议](../protocol/public/rest/prompt-settings.md)及[数据模型](../protocol/internal/data-model.md)为准。

## 验证内容

- 平台默认继承、自定义覆盖、显式空覆盖与恢复默认分别保存；世界与单聊/群聊会话提示词独立更新。
- 世界/会话 CAS 并发仅一个成功，失败不覆盖部分字段；角色常规编辑保留 Skills/MCP，显式空数组仍能清空，旧 revision 拒绝。
- Owner、Guest、会话成员和角色归属检查；不允许写入另一个 World 参数。实际物理 World 切换后重新认证，配置和未保存草稿不跨世界出现，切回仍读取已提交内容。
- 真实前后端和 fake 模型验证四层受控提示词标记进入实际系统输入；后台在第一请求执行中修改规则，第一请求继续使用旧来源，下一请求采用新版本，旧执行记录不改写。
- 预览、预算、规范化参数 Schema 与实际绑定采用共同能力结果；知识类扩展入口不要求所有能力都依赖文件根，当前实际类别仍是原生工作区与工作流控制。
- 存储异常返回安全错误，不泄露 SQL 参数或提示词；客户端丢失提交响应后通过读取核对，不重复写入或宣称已回滚。
- 未进入模型调用的上下文预算拒绝不伪造已采用来源；用量写入的有限重试、取消与实际返回记录保持原规则。
- 切换模块保留当前登录内的提示词草稿；冲突后查看/采用服务端版本；窄屏键盘返回、角色/设置弹窗焦点及原角色工具操作。

## 覆盖边界

本轮环境为 WSL2/Linux、Python 3.12、Node 24、Chromium、隔离 SQLite 与物理测试 World。Provider 验收使用确定性 fake，没有联网调用收费模型。PostgreSQL 仅离线 SQL，未验证实例部署；未进行 Windows 原生浏览器、其他浏览器或触摸设备实机验证。

提示词草稿只在当前登录内保留，不承诺刷新、退出登录或系统崩溃恢复；已保存配置由服务端迁移后的数据库持有。实际采用记录只保存版本/指纹，不保存或重建过去完整 Prompt。MCP 生命周期未在本批改动，既有内部 spike 不视为产品模块已经完成。
